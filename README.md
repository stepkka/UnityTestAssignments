# UnityTestAssignments

## Before doing any work
- Fork this repository into your GitHub account
- Clone your forked copy
- Make sure you're using the right Unity version
- Once you're done, create a pull request to merge the changes into main branch

## Basic test assignments
Open BasicTests_Unity project.

There are following test assignments available:
### TransformPivoting
There is ItemSlot object. There also is a Machete object that contain Pivot1 transform. Write a script that will make Machete a child of ItemSlot and move it so that Pivot1 has the same position and rotation as ItemSlot transform.

If done right, the machete should fit in green boxes.
